# Security Policy

## Supported Versions

Only the latest stable release of OverlayTrans receives security fixes.

## Reporting a Vulnerability

Please do not disclose security vulnerabilities in a public issue.

Use GitHub's private vulnerability reporting:

https://github.com/KaiyuanGONG/OverlayTrans/security/advisories/new

Include the affected OverlayTrans version, Windows version, reproduction steps, potential impact, and relevant logs or proof-of-concept material.

Remove API keys, personal information, and captured screen content before submitting a report. If an API key may have been exposed, revoke or rotate it immediately and never include the key itself.

## Security Scope

Security-relevant reports include API key exposure, unintended network requests, arbitrary code execution, command injection, unsafe local process handling, unintended screen capture, and installer-integrity issues.

Translation quality, provider availability, unsigned SmartScreen warnings, and functional bugs without a security impact belong in the regular issue tracker.

## Disclosure

Please allow reasonable time to investigate and release a fix before publicly disclosing a vulnerability.
