# README screenshot assets

This directory is reserved for release screenshots referenced by the English and Chinese README files.

Before adding a screenshot:

1. Capture the installed release build, not the development server.
2. Remove API keys, local paths, usernames, game content, and other private data.
3. Use descriptive lowercase names such as `capture-overlay.png`, `translation-panel.png`, and `settings-modes.png`.
4. Keep each image reasonably compressed and update both README files in the same commit.

Until reviewed screenshots exist, the READMEs intentionally link only to this contract instead of embedding a missing placeholder image.
